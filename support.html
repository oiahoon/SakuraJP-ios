常见问题

发现页暂时没有学习卡片怎么办？

先点击“重新加载”。如果仍为空，请到“我的”检查学习范围、内容偏好和学习模式；选择“全部内容”可以快速恢复有效范围。重新启动应用后仍无内容时，请联系支持。

影子跟读支持哪些导入方式？

可以选择 ZIP 或 MP3、M4A、WAV、AAC 文件，也可以输入有效的 HTTP/HTTPS 音频下载链接。教材由你提供，应用不附带测试用教材。链接导入需要网络；导入后的音频、录音和练习进度保存在设备内。

没有字幕也能练习吗？

可以。专门的影子跟读页按音频段支持先听、跟读、录音和回放，不要求教材必须带文本稿。

无法录音或回放自己的跟读？

请在 iOS“设置”中确认樱语拥有麦克风权限，并检查设备静音与音量。拒绝录音权限不会阻止音频播放与听力练习。

日语发音暂不可用？

在“我的 → 语音设置”中试听并选择可用的 iOS 日语声音，检查语速、音高与音量。必要时使用重置选项，再返回学习卡片重试。

AI 助手一定需要 API Key 吗？

不需要。内置学习解释来自应用随附的学习内容。只有当你主动选择 DeepSeek 或 OpenAI 在线生成时，才需要网络和对应提供商的 API Key。

如何备份收藏？

在“收藏”右上角管理入口选择 JSON 导出或导入；没有收藏时也可以导入。此功能备份收藏，不是学习记录和音频的完整备份。重新安装应用可能移除设备内的学习记录、音频与录音，因此在更换设备或删除应用前，请先导出重要收藏并保留原始教材文件。

句解是否必须联网？

不需要。本地分词和已审核语法规则先提供结果；在线 AI 增强是可选的。规则覆盖率描述随附语法例句，不代表对任意日语都能完全分析。

如何从学习卡片收藏、跟读或评定掌握？

右滑收藏，左滑换一张，点按打开详情。卡片上的波形入口开始跟读；长按可以选择掌握程度。辅助功能也提供对应的命名操作。

系统要求

  • iOS 26.0 或更高版本
  • 影子跟读录音需要麦克风权限
  • URL 音频导入与可选在线 AI 需要网络连接
  • 请为导入音频和录音预留足够的本地存储空间

反馈问题

  1. 确认应用已更新到 App Store 中的最新版本。
  2. 记录发生问题的页面与操作顺序。
  3. 附上设备型号、iOS 版本、应用版本；如不涉及个人学习内容，可附截图。
  4. 发送到支持邮箱或提交 GitHub Issue。请勿公开粘贴 API Key 或私人音频链接。
